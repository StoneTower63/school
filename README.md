# Hogwarts School API 🧙‍♂️✨

Веб-приложение для управления цифровой картотекой школы магии и волшебства «Хогвартс». Проект реализован на фреймворке *
*Spring Boot 3.3.0** с использованием архитектуры **MVC** (Model-View-Controller).

## 🚀 Стек технологий

* **Java 17** (Amazon Corretto)
* **Spring Boot 3.3.0** (Web, Spring Data JPA)
* **PostgreSQL** (Реляционная база данных для вечного хранения сущностей)
* **Hibernate / ORM** (Автоматическое управление схемами таблиц в режиме `update`)
* **Maven** (Сборщик проекта)
* **Springdoc OpenAPI v2 (Swagger UI)** (Интерактивная документация API)
* **Git / GitHub** (Система контроля версий)

## 🏗️ Архитектура проекта

Проект разделен на четыре независимых слоя по стандарту Enterprise-разработки:

1. `model` (Слой данных) — реляционные сущности `Student` и `Faculty` с разметкой JPA-аннотаций.
2. `repository` (Слой доступа к БД) — интерфейсы, наследующие `JpaRepository` для автоматической генерации SQL-запросов.
3. `service` (Слой бизнес-логики) — компоненты `@Service`, управляющие логикой через репозитории. Реализована жесткая
   валидация и защита от `null` через `Optional`.
4. `controller` (Веб-слой) — сетевые диспетчеры `@RestController` для обработки HTTP-запросов по REST-стандарту.

## 🛠️ Функционал API (CRUD + Фильтрация)

### Студенты (`/student`)

* `POST /student` — Создать студента (возвращает только уникальный `Long id`).
* `GET /student/{id}` — Получить полную информацию о студенте по его ID.
* `PUT /student` — Обновить данные мага (возвращает обновленный объект).
* `DELETE /student/{id}` — Удалить карточку студента из RAM (возвращает `void`).
* `GET /student?age=11` — Универсальный эндпоинт фильтрации магов по возрасту через `@RequestParam`.

### Факультеты (`/faculty`)

* Полный CRUD-цикл (`POST`, `GET`, `PUT`, `DELETE`).
* `GET /faculty?color=Red` — Фильтрация факультетов по цвету с использованием регистронезависимого поиска (
  `.equalsIgnoreCase()`).

## 🖥️ Запуск и тестирование

1. Скомпилируйте проект: `mvn clean package` или нажмите **Cmd + F9** в IntelliJ IDEA.
2. Запустите главный класс `SchoolApplication`. Встроенный сервер **Tomcat** поднимется на порту `8080`.
3. Откройте интерактивный фронтенд Swagger UI в браузере для тестирования эндпоинтов:
   [http://localhost:8080/swagger-ui/index.html](http://localhost:8080/swagger-ui/index.html)
