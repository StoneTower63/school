# Hogwarts School API 🧙‍♂️✨

Веб-приложение для управления цифровой картотекой школы магии и волшебства «Хогвартс». Проект реализован на фреймворке *
*Spring Boot 3.3.0** с использованием архитектуры **MVC** (Model-View-Controller).

## 🚀 Стек технологий

* **Java 17** (Amazon Corretto)
* **Spring Boot 3.3.0** (Web, Spring Data JPA [спринг дэ́йта джей-пи-эй])
* **PostgreSQL 15** [по́стгрэс кью-эл] (Реляционная база данных для вечного хранения сущностей)
* **Hibernate / ORM** [хайбэрне́йт] (Автоматическое управление схемами таблиц в режиме `update` [апде́йт])
* **Maven** [мэ́йвен] (Сборщик проекта)
* **Springdoc OpenAPI v2 (Swagger UI)** [сва́гэр ю-ай] (Интерактивная документация API)
* **Git / GitHub** [гит / гитха́б] (Система контроля версий)

## 🏗️ Архитектура проекта

Проект разделен на четыре независимых слоя по стандарту Enterprise-разработки:

1. `model` [мо́дэл] (Слой данных) — реляционные сущности `Student` [сту́дент], `Faculty` [фэ́кэлти] и `Avatar` [э́вэтар]
   с объектными связями `@ManyToOne` / `@OneToMany` и `@OneToOne` [эт уа́н ту уа́н — один к одному], защищёнными ленивой
   загрузкой `FetchType.LAZY` [фэтч тайп лэ́йзи] для предотвращения `OutOfMemoryError` [а́ут оф мэ́мори иксе́пшн].
2. `repository` [репо́зитори] (Слой доступа к БД) — интерфейсы, наследующие `JpaRepository` [джей-пи-эй репо́зитори] для
   автоматической генерации быстрых SQL-запросов [эс-кью-эл запро́сов].
3. `service` [се́рвис] (Слой бизнес-логики) — компоненты `@Service` [эт се́рвис], управляющие логикой через БД и потоки
   ввода-вывода `I/O Streams` [ай-оу стримз].
4. `controller` [контро́ллер] (Веб-слой) — сетевые диспетчеры `@RestController` [эт рэст контро́ллер] для обработки
   HTTP-запросов [эйч-ти-ти-пи запро́сов] по REST-стандарту [рэст станда́рту].

## 🛠️ Функционал API (CRUD + Фильтрация и Связи)

### Студенты (`/student`)

* `POST /student` — Создать студента (возвращает только уникальный `Long id` [лонг ай-ди] со статусом 201 Created).
* `GET /student/{id}` — Получить полную информацию о студенте по его ID из базы данных.
* `PUT /student` — Обновить данные мага на жёстком диске (возвращает обновленный объект).
* `DELETE /student/{id}` — Удалить карточку студента из PostgreSQL (возвращает `void` [войд], статус 204 No Content).
* `GET /student?min=10&max=15` — Оптимизированный поиск магов в промежутке возрастов через
  `@RequestParam` [эт рэ́квэст пара́м].
* `GET /student/{id}/faculty` — Получить факультет, к которому привязан конкретный студент (в одну строчку через
  сервис).

### Факультеты (`/faculty`)

* Полный CRUD-цикл (`POST`, `GET`, `PUT`, `DELETE`).
* `GET /faculty?nameOrColor=Gryff` — Универсальный регистронезависимый поиск по подстроке в имени или цвете факультета
  силами СУБД.
* `GET /faculty/{id}/student` — Получить список всех студентов, обучающихся на конкретном факультете.

### Аватарки и файлы (`/avatar`) — Добавлено в ДЗ 3.5:

* `POST /avatar/{studentId}` — Загрузить аватарку студента. Файл сохраняется параллельно на локальный диск в буферную
  папку `./avatars` и в виде бинарного массива в PostgreSQL. Возвращает `long id` аватара со статусом 201 Created.
* `GET /avatar/{studentId}/from-db` — Скачать аватарку студента напрямую из базы данных (возвращает `byte[]` с
  прописыванием HttpHeaders).
* `GET /avatar/{studentId}/from-file` — Высокопроизводительное скачивание аватарки транзитом с жесткого диска Mac через
  `HttpServletResponse.getOutputStream()` без перегрузки кучи Heap.

## 📊 Аналитика и Базы Данных

В корне проекта создан файл `scripts.sql` [скриптс эс-кью-эл], содержащий 5 каноничных
SELECT-запросов [сэле́кт запро́сов] на чистом языке SQL для прямой работы с таблицами через pgAdmin
4 [пи-джи адми́н фо].

## 🖥️ Запуск и тестирование

1. Скомпилируйте проект: нажмите **Option + Command + L (⌥⌘L)** для красоты кода, а затем **Command + F9 (⌘F9)** для
   сборки в IntelliJ IDEA [инте́ллидж э́йдиа].
2. Запустите главный класс `SchoolApplication` [скул апплике́ишн]. Встроенный сервер **Tomcat** [то́мкэт] поднимется на
   порту `8080`.
3. Откройте интерактивный фронтенд Swagger UI в браузере для тестирования
   эндпоинтов: http://localhost:8080/swagger-ui/index.html
